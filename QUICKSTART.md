# Quick Start Guide

## Fast Setup (3 Steps)

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm start
```

### 3. Open Browser
Navigate to: `http://localhost:3000`

That's it! The website should now be running.
